# 1c-dev-rules

> Универсальный подключаемый набор правил разработки **1С:Предприятие 8** для ИИ-ассистентов (ZCode, Claude, Codex, Cursor). Основан на стандартах [v8std](https://github.com/zeegin/v8std) и адаптирован под реальные грабли продакшен-разработки.

Один плагин — много скилов. Каждый скил = тематический набор правил с мини-чек-листом и развёрнутыми карточками в `references/` (progressive disclosure: скил в system-reminder короткий, детали подгружаются по требованию).

## Что внутри

**21 скил** + 28 карточек-ссылок + 15 справочников стандартов v8std покрывают весь цикл разработки 1С — от планирования задачи до код-ревью:

| Скил | Назначение |
|---|---|
| `1c-dispatch-gate` | 🚪 **Главный маршрутизатор** — открывается первым. Гейт-чек-лист «сигнал → карточки» + таблица по типу работы |
| `1c-project-bootstrap` | 🚀 Генератор `AGENTS.md` и `.zcode/config.json` для нового проекта с правильными ссылками на набор |
| `1c-arch-checklist` | 7 вопросов эксперта **до** написания кода: где жить логике, есть ли готовое, что при отказе, индексы… |
| `1c-thin-triggers` | 🔥 Построчный чек-лист самопроверки по **5 слоям** (механика, архитектура, перф, отказоустойчивость, галлюцинации API) |
| `1c-code-review` | Чек-лист ревью MR по секциям: модуль, запросы, форма, проведение, данные, роли, РЗ |
| `1c-queries` | Запросы, СКД, динамические списки (№655, №733, №436, №656…) + проектирование СКД |
| `1c-forms` | Формы, архетипы, типовые (создание/доработка), `modifiesStoredData`, 5 обязательных областей |
| `1c-metadata` | Метаданные, ручная правка XML (`.mdo`/`.form`), скелеты модулей, проектирование регистров |
| `1c-events-transactions` | Проведение, блокировки, транзакции (№783, №460, №661), шаблон короткой транзакции |
| `1c-logging` | Журналирование, исключения (№499, №790), `ЗаписьЖурналаРегистрации` |
| `1c-performance` | Производительность, серверные вызовы, кэш, индексы |
| `1c-security` | Права, RLS, привилегированный режим, новые объекты (№532) |
| `1c-scheduled` | Регламентные задания (№539, №540), идемпотентность, устойчивость |
| `1c-integration` | Интеграция, HTTP, таймауты, обмен данными |
| `1c-async` | `Асинх`/`Ждать` (8.3.18+), ловушки потери исключений |
| `1c-extensions` | Расширения (CFE), перехватчики `&Перед`/`&После`, `ПродолжитьВызов` |

| `1c-ui-ux` | Командный интерфейс, стилистика, UX |

## Как подключить в ZCode

### Вариант 1 — как плагин с GitHub (после публикации)

1. В ZCode: **Settings → Plugin Management → Discover → `+`**
2. Вставьте URL репозитория: `https://github.com/<owner>/1c-dev-rules`
3. **Install** — плагин включён по умолчанию, все скилы сразу появятся в system-reminder

### Вариант 2 — как локальный каталог (для разработки/тестирования)

```bash
git clone <repo> ~/Projects/1c-dev-rules
```

В `~/.zcode/cli/config.json` добавьте путь в `plugins.dirs`:
```json
{
  "plugins": {
    "enabled": true,
    "dirs": ["~/Projects/1c-dev-rules"]
  }
}
```

Или положите ссылку в `.zcode/skills/` вашего проекта — скилы подхватятся.

## Как использовать

### Онбординг нового проекта

В корне нового проекта вызовите:
```
/1c-project-bootstrap
```

Скил спросит: префикс объектов (`торо_`/`гкс_`/другой), путь к исходникам, `compatibilityMode`. Сгенерирует:
- `AGENTS.md` с универсальными секциями + заглушками под проектные детали
- `.zcode/config.json` с подключением плагина

### Повседневная работа

При любой задаче открывается `1c-dispatch-gate` — он маршрутизирует к нужным карточкам. При самопроверке — `1c-thin-triggers`. Подробности — в каждом скиле.

## Источники и лицензии

Набор собран из трёх открытых репозиториев (см. [docs/SOURCES.md](./docs/SOURCES.md)):

- **[zeegin/v8std](https://github.com/zeegin/v8std)** — стандарты разработки 1С (~360 стандартов). Карточки ссылаются на первоисточник.
- **[comol/ai_rules_1c](https://github.com/comol/ai_rules_1c)** — практика кодирования (public domain). Лежит в основе practice-карточек.
- **[Nikolay-Shirokov/cc-1c-skills](https://github.com/Nikolay-Shirokov/cc-1c-skills)** — спецификации метаданных и форматов 1С.

Лицензия набора — **MIT** (см. [LICENSE](./LICENSE)). Сохранены ссылки на оригинальные стандарты; этот репозиторий — удобная упаковка их в скилы ИИ.

## Архитектура набора

Подробно — в [docs/ARCHITECTURE.md](./docs/ARCHITECTURE.md). Кратко:

```
1c-dev-rules/
├── .zcode-plugin/plugin.json   ← манифест плагина
├── skills/                     ← 21 скил (каждый = каталог)
│   └── <name>/
│       ├── SKILL.md            ← frontmatter + мини-сводка (≤500 строк)
│       └── references/*.md     ← полные карточки, progressive disclosure
├── std/                        ← 15 оглавлений v8std (справочный слой)
└── docs/                       ← ARCHITECTURE, SOURCES, CHANGELOG
```

Принцип: **универсальные правила здесь, проектная специфика — в `AGENTS.md` проекта**. Скилы не содержат упоминаний конкретных конфигураций.
