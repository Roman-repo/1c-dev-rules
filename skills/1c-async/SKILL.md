# 1c-async — асинхронный код и запрет модальности

> В управляемых формах (№703) — никаких модальных окон и синхронных вызовов. Только асинхронные аналоги. Начиная с 8.3.18 — нативный синтаксис `Асинх`/`Ждать`.

## 🔴 №703 — Запрет модальных окон и синхронных вызовов

В управляемых формах — **никаких**:
- `ОткрытьФормуМодально(...)` → `ОткрытьФорму(...)` + `ОписаниеОповещения`
- `Предупреждение(...)` → `ПоказатьПредупреждение(...)`
- `Вопрос(...)` → `ПоказатьВопрос(...)`

Это требование веб-клиента и совместимости.

## Два способа async в 1С

### 1. Старый (через callback'и) — для совместимости со старыми версиями
```bsl
Оповещение = Новый ОписаниеОповещения("ПослеВопроса", ЭтотОбъект);
ПоказатьВопрос(Оповещение, "Удалить?", РежимДиалогаВопрос.ДаНет);
```

### 2. Новый (`Асинх`/`Ждать`, 8.3.18+) — читаемее
```bsl
Асинх Процедура УдалитьОбъект()
    Ответ = Ждать ПоказатьВопросАсинх("Удалить?", РежимДиалогаВопрос.ДаНет);
    Если Ответ = КодВозвратаДиалога.Да Тогда
        // ...
    КонецЕсли;
КонецПроцедуры
```

⚠️ **Проверьте `compatibilityMode` в `Configuration.mdo`** — `Асинх`/`Ждать` доступны только с 8.3.18+. Для более старых — только callback'и (`ОписаниеОповещения`).

## 🔴 Ловушка: обработчики событий формы нельзя делать `Асинх`

`Асинх Процедура ПриОткрытии(...)` / `ПередЗакрытием(...)` / `ПриИзменении(...)` — **нельзя**. Платформа игнорирует параметр `Отказ` в асинх-обработчике, поэтому:

❌ `Асинх Процедура ПередЗаписью(Отказ)` — `Отказ` не сработает
✅ Обычная процедура + внутри вызов асинх-метода с callback

## 🔴 Ловушка: исключения теряются без `Ждать`

Вызов `*Асинх` без `Ждать` — асинхронный «огонь и забыл». Если внутри возникнет исключение, оно **потеряется молча**.

❌ `ПоказатьВопросАсинх("...");` — без `Ждать`, исключение потеряется
✅ `Ответ = Ждать ПоказатьВопросАсинх("...");` — с `Ждать`

## Тяжёлые операции (№642/№755)

Тяжёлые расчёты (более 2–3 сек) — в **фоновом задании** (`НачатьВыполнениеНаСервере` / `ФоновыеЗадания.Выполнить`), не в интерактивном сеансе. На клиенте — асинхронно с индикатором прогресса.

---

## Мини-чек-лист по async

- [ ] Нет модальных окон / синхронных вызовов (№703)
- [ ] `ОткрытьФормуМодально`/`Предупреждение`/`Вопрос` → `Показать*` аналоги
- [ ] `Асинх`/`Ждать` только если `compatibilityMode >= 8.3.18` (иначе callback'и)
- [ ] Обработчики событий формы **не** `Асинх` (Отказ игнорируется)
- [ ] `*Асинх`-вызовы — с `Ждать` (иначе исключение потеряется)
- [ ] Тяжёлые операции — в фоновом задании (№642)
