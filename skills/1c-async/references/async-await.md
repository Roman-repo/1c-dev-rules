# Практика: Асинхронные методы (Асинх / Ждать / Обещание)

> Шаблоны и ловушки асинхронного механизма платформы 8.3.18+.
> Адаптировано из [`async-methods.md`](https://github.com/comol/ai_rules_1c/blob/main/content/rules/async-methods.md) репозитория `ai_rules_1c`.

## Когда применять

При написании/ревью клиентского кода с асинхронными вызовами (`&НаКлиенте`), особенно при переходе со старых `Показать*` + `ОписаниеОповещения` на новый синтаксис `Асинх`/`Ждать`.

---

## Базовые принципы

1. Каждая новая асинхронная функция (суффикс `Асинх`) возвращает объект `Обещание` (Promise).
2. `Ждать` — оператор ожидания. Код после `Ждать` не выполняется, пока обещание не разрешится.
3. `*Асинх`-методы можно вызывать **только** внутри процедур/функций, объявленных с ключевым словом `Асинх`.
4. `Обещание` имеет три состояния: **Ожидание**, **Успех**, **Провал**.
5. Механизм работает **только на клиенте** (`&НаКлиенте`).

---

## Соответствие старых и новых методов

Предпочитайте новый синтаксис `*Асинх` вместо `Показать*` с `ОписаниеОповещения`:

| Модальное (запрещено) | Через callback | Новый `Асинх` |
|---|---|---|
| `Предупреждение()` | `ПоказатьПредупреждение()` | `ПредупреждениеАсинх()` |
| `Вопрос()` | `ПоказатьВопрос()` | `ВопросАсинх()` |
| `ОткрытьЗначение()` | `ПоказатьЗначение()` | `ОткрытьЗначениеАсинх()` |
| `ВвестиЧисло()` | `ПоказатьВводЧисла()` | `ВвестиЧислоАсинх()` |
| `НайтиФайлы()` | `НачатьПоискФайлов()` | `НайтиФайлыАсинх()` |
| `ПоместитьФайлы()` | `НачатьПомещениеФайлов()` | `ПоместитьФайлыНаСерверАсинх()` |

---

## Возвращаемые значения `Ждать`

| Метод | Результат `Ждать Обещание` |
|---|---|
| `ПредупреждениеАсинх` | `Неопределено` |
| `ВопросАсинх` | `КодВозвратаДиалога` |
| `ОткрытьЗначениеАсинх` | `Неопределено` |
| `ВвестиЧислоАсинх` | `Число` |
| `НайтиФайлыАсинх` | `Массив` объектов `Файл` |
| `ПоместитьФайлыНаСерверАсинх` | `Массив` `ОписаниеПомещенногоФайла` (успех) / `Неопределено` (провал) |

## Базовый шаблон

```bsl
&НаКлиенте
Асинх Процедура МояПроцедура()

    Обещание = ВопросАсинх("Продолжить?", РежимДиалогаВопрос.ДаНет);
    Результат = Ждать Обещание;

    Если Результат = КодВозвратаДиалога.Да Тогда
        // Действие
    КонецЕсли;

КонецПроцедуры
```

---

## 🔴 Критическое правило 1: без `Ждать` исключения теряются

Если вызвать асинхронную функцию без `Ждать` и внутри возникнет исключение, оно **проглатывается бесследно**. Код продолжается, как будто ничего не произошло.

```bsl
// ОПАСНО: исключение внутри ВызватьОшибку() потеряно!
Процедура МояПроцедура(Команда)
    ВызватьОшибку();   // асинхронная функция без Ждать
КонецПроцедуры

Асинх Функция ВызватьОшибку()
    ВызватьИсключение "ошибка!";   // никто этого не увидит
КонецФункции
```

**Правило:** Всегда используйте `Ждать` при вызове `Асинх`-функций, если важен результат или обработка ошибок. Без `Ждать` — только для сценариев «выстрелил-забыл», где результат и ошибки намеренно игнорируются.

---

## 🔴 Критическое правило 2: `Асинх` в обработчиках событий формы НЕ блокирует

Обработчики событий формы (`ПриОткрытии`, `ПередЗакрытием`), объявленные с `Асинх`, **ведут себя не так, как ожидается** — платформа не дожидается их завершения.

```bsl
// НЕ РАБОТАЕТ! Форма откроется, Отказ = Истина проигнорирован.
&НаКлиенте
Асинх Процедура ПриОткрытии(Отказ)
    Отказ = Истина;                    // платформа уже пошла дальше
    ВызватьИсключение "ошибка!";       // пользователь увидит ошибку, но форма уже открыта
КонецПроцедуры
```

**Правило:** **Не делать** обработчики событий формы (`ПриОткрытии`, `ПередЗакрытием`, `ПриЗаписиНаСервере` и т.д.) асинхронными. Параметр `Отказ` и любое влияние на поток выполнения формы будут проигнорированы. Вместо этого — вызывайте отдельную `Асинх`-процедуру из обычного обработчика.

---

## ✅ Паттерн: вопрос при открытии формы

`ПриОткрытии` — обычная процедура, вызывает отдельную `Асинх`-процедуру:

```bsl
&НаКлиенте
Процедура ПриОткрытии(Отказ)
    ЗадатьВопросПриОткрытии();
КонецПроцедуры

&НаКлиенте
Асинх Процедура ЗадатьВопросПриОткрытии()

    Обещание = ВопросАсинх("Продолжить работу?",
        РежимДиалогаВопрос.ДаНет, , КодВозвратаДиалога.Да);
    Результат = Ждать Обещание;

    Если Результат <> КодВозвратаДиалога.Да Тогда
        ЭтаФорма.Закрыть();
    КонецЕсли;

КонецПроцедуры
```

---

## ✅ Паттерн: вопрос при закрытии формы

Флаг-переменная предотвращает рекурсию:

```bsl
&НаКлиенте
Перем ВопросПриЗакрытииЗадан;

&НаКлиенте
Процедура ПередЗакрытием(Отказ, ЗавершениеРаботы,
        ТекстПредупреждения, СтандартнаяОбработка)

    Если НЕ ВопросПриЗакрытииЗадан Тогда
        ЗадатьВопросПриЗакрытии();
        Отказ = Истина;
    КонецЕсли;

КонецПроцедуры

&НаКлиенте
Асинх Процедура ЗадатьВопросПриЗакрытии()

    Обещание = ВопросАсинх("Закрыть форму?",
        РежимДиалогаВопрос.ДаНет, , КодВозвратаДиалога.Да);
    Результат = Ждать Обещание;

    Если Результат = КодВозвратаДиалога.Да Тогда
        ВопросПриЗакрытииЗадан = Истина;
        ЭтаФорма.Закрыть();
    КонецЕсли;

КонецПроцедуры

ВопросПриЗакрытииЗадан = Ложь;
```

## ✅ Паттерн: работа с файлами

```bsl
&НаКлиенте
Асинх Процедура ЗагрузитьФайлыНаСервер()

    Обещание = НайтиФайлыАсинх(ПутьКПапке, "*.*", Ложь);
    НайденныеФайлы = Ждать Обещание;

    ДобавляемыеФайлы = Новый Массив;
    Для Каждого НайденныйФайл Из НайденныеФайлы Цикл
        Описание = Новый ОписаниеПередаваемогоФайла;
        Описание.Имя = НайденныйФайл.ПолноеИмя;
        ДобавляемыеФайлы.Добавить(Описание);
    КонецЦикла;

    Обещание = ПоместитьФайлыНаСерверАсинх(
        , , ДобавляемыеФайлы, ЭтаФорма.УникальныйИдентификатор);
    Результат = Ждать Обещание;

КонецПроцедуры
```

## HTTP-методы (платформа 8.3.21+)

`HTTPСоединение` предоставляет асинхронные аналоги (суффикс `Асинх`): `ВызватьHTTPМетодАсинх`, `ЗаписатьАсинх`, `ПолучитьАсинх` и т.д. Те же правила: вызывающий код должен быть `Асинх`, используйте `Ждать` для получения результата и обработки исключений.

---

## Чек-лист ревью асинхронного кода

- [ ] Все вызовы `*Асинх`-методов либо с `Ждать`, либо намеренно «выстрелил-забыл» (с комментарием)
- [ ] Обработчики событий формы (`ПриОткрытии`, `ПередЗакрытием`) **не** объявлены `Асинх`
- [ ] Команды формы могут быть `Асинх` — это безопасно
- [ ] Исключения в асинхронных функциях не «проглатываются» молча
