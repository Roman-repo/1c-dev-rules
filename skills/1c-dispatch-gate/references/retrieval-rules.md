# Навигационный слой: правила поиска стандартов

> Адаптация [`retrieval-rules.yml`](https://github.com/zeegin/v8std/blob/main/retrieval-rules.yml) из репозитория v8std.
> Этот файл — **словарь синонимов** для ИИ-модели: связывает фрагменты кода, поисковые фразы и диагнозы с конкретными стандартами.

## Зачем этот файл

Каталог карточек отвечает на вопрос «что требует стандарт». Этот файл отвечает на другой вопрос: **«увидев в коде X или услышав запрос Y — какой стандарт открыть?»**. Превращает каталог из справочника в навигационный слой.

## Как пользоваться (для ИИ-модели)

1. Встретили в коде вызов метода из колонки `snippet_calls` → проверьте стандарты из `standards`.
2. Пользователь написал синоним из колонки `aliases` → отсылайте к стандартам из `standards`.
3. Сработала диагностика из `diagnostics` → стандарт-источник указан в `standards`.
