## №648 — Ответственное чтение данных

**Критичность:** 🔴 Блокирующее

**Суть:** Не читать «на всякий случай» весь объект. Если нужно 2 поля — читайте 2 поля, а не `Объект.Ссылка` целиком. Используйте `ОбщегоНазначения.ЗначенияРеквизитовОбъекта(...)` или точечный запрос.

❌ **Неправильно:**
```bsl
ДокСсылка = Документы.ЗаявкаНаРемонт.НайтиПоНомеру(1);
ДокОбъект = ДокСсылка.ПолучитьОбъект();     // вытянули ВСЕ реквизиты
Если ДокОбъект.Организация = НашаОрганизация Тогда ...
```

✅ **Правильно:**
```bsl
Поля = "Организация";
Значения = ОбщегоНазначения.ЗначенияРеквизитовОбъекта(ДокСсылка, Поля);
Если Значения.Организация = НашаОрганизация Тогда ...
```

🔍 Авто-проверка: `#bslls:MethodReferenceGetForm`
📖 [Полный текст](https://github.com/zeegin/v8std/blob/main/docs/std/648.md)
См. также: №496

## №783 — Транзакции: правила использования

**Критичность:** 🔴 Блокирующее

**Суть:** Транзакция должна быть **короткой** и охватывать только запись. Не читать данные внутри транзакции (особенно с блокировкой), не вызывать `ПоказатьВопрос`, не делать серверных вызовов «наружу».

Шаблон (как в БСП):
```bsl
// Чтение и подготовка данных — ДО транзакции
ДанныеДляЗаписи = ПодготовитьДанные();   // запросы, .ПолучитьОбъект(), вычисления

НачатьТранзакцию();
Попытка
    // ... только запись ...
    ЗаписатьДанные(ДанныеДляЗаписи);
    ЗафиксироватьТранзакцию();
Исключение
    ОтменитьТранзакцию();
    ВызватьИсключение;   // обязательно!
КонецПопытки;
```

❌ **Неправильно** (инцидент Б7):
```bsl
НачатьТранзакцию();
Попытка
    Выборка = Запрос.Выполнить().Выбрать();   // 🔴 чтение ВНУТРИ транзакции
    Пока Выборка.Следующий() Цикл
        // ... удаление/запись ...
    КонецЦикла;
    ЗафиксироватьТранзакцию();
Исключение
    ОтменитьТранзакцию();
    ВызватьИсключение;
КонецПопытки;
```

✅ **Правильно** — вынести чтение до `НачалоТранзакции()`:
```bsl
МассивКУдалению = Запрос.Выполнить().Выгрузить();   // чтение ДО транзакции

НачатьТранзакции();
Попытка
    Для Каждого Запись Из МассивКУдалению Цикл
        // ... только запись/удаление ...
    КонецЦикла;
    ЗафиксироватьТранзакцию();
Исключение
    ОтменитьТранзакцию();
    ВызватьИсключение;
КонецПопытки;
```

> ⚠️ **Исключение:** чтение внутри транзакции допустимо для read-modify-write с **явной `БлокировкаДанных`** (см. [practice/locks-transactions.md §3](./practice/locks-transactions.md)) — когда без блокировки нельзя гарантировать консистентность остатка. Это осознанный компромисс с комментарием-обоснованием.

📖 [Полный текст](https://github.com/zeegin/v8std/blob/main/docs/std/783.md)
См. также: №659 (избыточные блокировки), №661 (блокирующее чтение остатков), [thin-triggers.md → «Чтение между НачалоТранзакции и ЗафиксироватьТранзакции»](./thin-triggers.md)

## №460 — Управляемый режим блокировки

**Критичность:** 🔴 Блокирующее

**Суть:** В прикладном коде — управляемые блокировки (`БлокировкаДанных`), не исключительные. Исключительные блокировки — только в особых случаях, с обоснованием в комментарии.

📖 [Полный текст](https://github.com/zeegin/v8std/blob/main/docs/std/460.md)

## №724 — Модули с повторным использованием возвращаемых значений

**Критичность:** 🟡 Важно

**Суть:** Если общий модуль возвращает данные, слабо меняющиеся между вызовами (справочники, константы, ФО) — включите ему «повторное использование возвращаемых значений» (`Сеанс` или `На время вызова`). Это кардинально снижает число запросов к БД.

✅ **Как в проект (хорошо):** многие общие модули БСП (`ОбщегоНазначения`, `Пользователи`) уже с повторным использованием. Для прикладных модулей с «чистыми» функциями-геттерами — делайте так же.

📖 [Полный текст](https://github.com/zeegin/v8std/blob/main/docs/std/724.md)

## №646 / №307 — Структура модуля и порядок

**Критичность:** 🟡 Важно

**Суть:** Модуль делится областями в строго определённом порядке. Для модуля объекта/формы:
`ОбработчикиСобытий` → `ПрограммныйИнтерфейс` → `СлужебныйПрограммныйИнтерфейс` → `СлужебныеПроцедурыИФункции`.
См. шаблон в [`CLAUDE.md`](../../CLAUDE.md), раздел 2.

🔍 Авто-проверка: `#bslls:EmptyRegion`, `#bslls:NonStandardRegion`

## №413 — Использование параметров сеанса

**Критичность:** 🟡 Важно

**Суть:** Параметры сеанса — для часто читаемых значений, влияющих на поведение (текущий пользователь, организация, язык). Не использовать как хранилище промежуточных данных. Чтение параметра сеанса — быстро, изменение — дорого (пересчёт RLS).

📖 [Полный текст](https://github.com/zeegin/v8std/blob/main/docs/std/413.md)
См. также: №491 (влияние на RLS)

## №455 / №456 / №441 — Структура и тексты модулей

**Критичность:** 🟡 Важно

**Суть:**
- **№455 Структура модуля** — стандартный порядок областей (см. CLAUDE.md §2).
- **№456 Тексты модулей** — отступы табуляцией, пробелы вокруг операторов, комментарии для нетривиальной логики, длина строки ≤ 120 символов.
- **№441 Конструкции языка** — использовать только проверенные конструкции; избегать неочевидных трюков, затрудняющих чтение.

📖 №455 [структура](https://github.com/zeegin/v8std/blob/main/docs/std/455.md) · №456 [тексты](https://github.com/zeegin/v8std/blob/main/docs/std/456.md) · №441 [конструкции](https://github.com/zeegin/v8std/blob/main/docs/std/441.md)

## №454 / №647 — Имена переменных, процедур, функций

**Критичность:** 🔴 Блокирующее

**Суть:**
- **№454 Имена переменных** — CamelCase с заглавной, отражают смысл, не тип. Булевы — с вопроса (`ЭтоНовый`). Запрещены венгерская нотация и префиксы `п`, `тз`, `вт`.
- **№647 Имена процедур/функций** — начинаются с глагола (`Получить...`, `Установить...`, `Проверить...`), отражают действие.

📖 №454 [переменные](https://github.com/zeegin/v8std/blob/main/docs/std/454.md) · №647 [процедуры](https://github.com/zeegin/v8std/blob/main/docs/std/647.md)

**Критичность:** 🟡 Важно

## №443 — Получение предопределённых значений на клиенте

**Критичность:** 🔴 Блокирующее

**Суть:** На клиенте нельзя вызвать `ПредопределенноеЗначение("Справочник...")` — это серверная функция. Кэшируйте предопределённые в реквизитах формы на сервере, либо используйте серверные вызовы.

📖 [Полный текст](https://github.com/zeegin/v8std/blob/main/docs/std/443.md)

## №432 — Реквизиты строкового типа

**Критичность:** 🟡 Важно

**Суть:** Для строковых реквизитов указывайте длину (не «0» = неограниченная, кроме случаев хранения длинных текстов). Неограниченные строки — нельзя индексировать и соединять, осторожнее.

## №447 — `РегистрСведенийМенеджерЗаписи`

**Критичность:** 🟡 Важно

**Суть:** Для записи в непериодический регистр сведений используйте `РегистрСведенийМенеджерЗаписи`, для пакетной — набор записей. Не путать с менеджером регистра (`РегистрСведений.Имя.СоздатьМенеджерЗаписи()`).

## №448 — Копирование строк между таблицами

**Критичность:** 🟡 Важно

**Суть:** Используйте `ЗаполнитьЗначенияСвойств(Приёмник, Источник)` для копирования совпадающих по именам колонок. Не копируйте по одному полю через присваивание — многословно и хрупко.

📖 [Полный текст](https://github.com/zeegin/v8std/blob/main/docs/std/448.md)

## №449 — Представления ссылочных значений в табдоке

**Критичность:** 🟡 Важно

**Суть:** Чтобы получить представления ссылок для вывода в табличный документ, используйте `ПолучитьПредставленияСсылок(...)` или `ПолучитьПредставление(...)` БСП — не разыменование через точку и не `Строка(Ссылка)`.

📖 [Полный текст](https://github.com/zeegin/v8std/blob/main/docs/std/449.md)

## №451 — Программное создание прикладных объектов

**Критичность:** 🟡 Важно

**Суть:** Для программного создания объектов используйте менеджеры (`Документы.Имя.СоздатьДокумент()`), а не `Новый СправочникОбъект.Имя(...)`. Последний некорректно работает в тонком клиенте и веб-клиенте.

📖 [Полный текст](https://github.com/zeegin/v8std/blob/main/docs/std/451.md)

## №452 — Поиск в коллекциях значений

**Критичность:** 🟡 Важно

**Суть:** Для поиска в коллекциях используйте встроенные методы: `.Найти(...)`, `.НайтиСтроки(...)`. Не цикл `Для каждого` с ручной проверкой — это медленно и многословно. Если поиска много — используйте `Соответствие`.

📖 [Полный текст](https://github.com/zeegin/v8std/blob/main/docs/std/452.md)

**Критичность:** 🔴 Блокирующее

## №693 — Использование объектов типа Структура

## №723 — Разработка для Linux/macOS

**Критичность:** 🟡 Важно

**Суть:** Код, работающий на сервере, должен быть переносимым: пути через `/`, учёт регистра в именах файлов, отсутствие COM-зависимостей. Не предполагать Windows.

## №782 — Массовая конкатенация строк

**Критичность:** 🔴 Блокирующее

**Суть:** Конкатенация строк в цикле через `+` — квадратичная сложность (O(n²)). Для массовой сборки строк используйте `СтрСоединить(Массив, Разделитель)` — O(n).

❌ **Неправильно:**
```bsl
Текст = "";
Для Каждого Стр Из Данные Цикл
    Текст = Текст + Стр.Поле + ";";   // O(n²) — тормозит на больших N
КонецЦикла;
```

✅ **Правильно:**
```bsl
Части = Новый Массив;
Для Каждого Стр Из Данные Цикл
    Части.Добавить(Стр.Поле);
КонецЦикла;
Текст = СтрСоединить(Части, ";");   // O(n)
```

📖 [Полный текст](https://github.com/zeegin/v8std/blob/main/docs/std/782.md)

## Мини-чек-лист по коду/модулям

- [ ] Чтение данных точечное, не «объект целиком» (№648)
- [ ] Транзакции короткие, только запись (№783)
- [ ] Блокировки управляемые (№460)
- [ ] Структура модуля по областям, в правильном порядке (№646)
- [ ] Чистые геттеры — с повторным использованием (№724)
- [ ] Имена: CamelCase, без `ё` в метаданных, без венгерской нотации (CLAUDE.md §1)
- [ ] Экспортные процедуры — с описанием (CLAUDE.md §9)
