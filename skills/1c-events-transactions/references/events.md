## №686 — Работа с параметром «Отказ»

**Критичность:** 🔴 Блокирующее

**Суть:** В обработчиках событий (`ПередЗаписью`, `ОбработкаПроверкиЗаполнения` и др.) для отказа используйте **только** присваивание `Отказ = Истина`. Никогда не `Возврат` без установки отказа, и не смешивайте бизнес-проверки с установкой отказа через сложные условия.

❌ **Неправильно:**
```bsl
Процедура ОбработкаПроверкиЗаполнения(Отказ, ПроверяемыеРеквизиты)
    Если ПустаяСтрока(Наименование) Тогда
        Возврат;   // продолжится запись с пустым наименованием!
    КонецЕсли;
КонецПроцедуры;
```

✅ **Правильно:**
```bsl
Процедура ОбработкаПроверкиЗаполнения(Отказ, ПроверяемыеРеквизиты)
    Если ПустаяСтрока(Наименование) Тогда
        Отказ = Истина;
        ОбщегоНазначенияКлиентСервер.СообщитьПользователь(
            "Не заполнено наименование", , , "Наименование");
    КонецЕсли;
КонецПроцедуры;
```

🔍 Авто-проверка: `#bslls:IfElseIfCondition`
📖 [Полный текст](https://github.com/zeegin/v8std/blob/main/docs/std/686.md)

## №522 — Обращение к данным ИБ в часто вызываемых событиях

**Критичность:** 🔴 Блокирующее

**Суть:** Обработчики `ПриПолученииДанныхНаСервере`, `ПриАктивизацииСтроки`, `ПриИзменении` вызываются **очень часто**. В них нельзя делать запросы к БД, тяжёлые расчёты, серверные вызовы. Кэшируйте данные при открытии формы.

📖 [Полный текст](https://github.com/zeegin/v8std/blob/main/docs/std/522.md)
См. также: №459, №629

## №464 / №465 — ПередЗаписью / ПриЗаписи

**Критичность:** 🔴 Блокирующее

**Суть:**
- **`ПередЗаписью`** — подготовка данных (дозаполнение реквизитов, номера, дат). Чтение/запись других объектов — нежелательно.
- **`ПриЗаписи`** — запись зависимых данных, регистрация в очереди. Транзакция уже открыта, поэтому действия должны быть быстрыми и не вызывать интерактив.

📖 №464 [ПередЗаписью](https://github.com/zeegin/v8std/blob/main/docs/std/464.md) · №465 [ПриЗаписи](https://github.com/zeegin/v8std/blob/main/docs/std/465.md)

## №773 — Признак `ОбменДанными.Загрузка` в обработчиках

**Критичность:** 🟡 Важно

**Суть:** В обработчиках записи проверяйте `ОбменДанными.Загрузка` — при обмене данными (интеграция) часть проверок и автозаполнений нужно пропускать, чтобы не сломать загружаемые данные.

✅ **Правильно:**
```bsl
Процедура ПередЗаписью(Отказ)
    Если ОбменДанными.Загрузка Тогда
        Возврат;  // при обмене не пересчитываем
    КонецЕсли;
    // ... автозаполнение
КонецПроцедуры;
```

📖 [Полный текст](https://github.com/zeegin/v8std/blob/main/docs/std/773.md)

## №463 — ОбработкаПроверкиЗаполнения

**Критичность:** 🟡 Важно

**Суть:** Не дублируйте стандартную проверку заполнения. Используйте `ПроверяемыеРеквизиты` для точечных проверок, не предусмотренных свойством «Проверка заполнения».

📖 [Полный текст](https://github.com/zeegin/v8std/blob/main/docs/std/463.md)

## №396 — Обработчик `ОбработкаЗаполнения`

**Критичность:** 🟡 Важно

**Суть:** `ОбработкаЗаполнения` срабатывает при создании нового на основании. Не дублировать здесь автозаполнение по умолчанию (платформа сама копирует реквизиты-связи). Использовать для нестандартной логики дозаполнения и проверки основания.

📖 [Полный текст](https://github.com/zeegin/v8std/blob/main/docs/std/396.md)

## №450 — Порядок записи движений документов

**Критичность:** 🟡 Важно

**Суть:** Движения по регистрам записываются в `ОбработкаПроведения`. Порядок записи влияет на блокировки и итоги. Использовать набор записей с очисткой перед записью; записывать пакетно, не по одному регистру.

📖 [Полный текст](https://github.com/zeegin/v8std/blob/main/docs/std/450.md)
См. также: №792

## №492 — Обработчики событий формы, подключаемые из кода

**Критичность:** 🟡 Важно

**Суть:** События формы, не имеющие стандартного обработчика, подключайте через `ДобавитьОбработчик Элемент.Событие, "ИмяПроцедуры"` или `ОписаниеОповещения`. Не через присваивание и не через глобальные перехватчики.

📖 [Полный текст](https://github.com/zeegin/v8std/blob/main/docs/std/492.md)

## Мини-чек-лист по событиям

- [ ] Отказ устанавливается `Отказ = Истина`, не `Возврат` (№686)
- [ ] В часто вызываемых событиях нет запросов к БД (№522)
- [ ] `ПередЗаписью` — только подготовка, `ПриЗаписи` — короткие действия (№464/465)
- [ ] Учтён `ОбменДанными.Загрузка` при необходимости (№773)
- [ ] Проверка заполнения не дублирует стандартную (№463)
