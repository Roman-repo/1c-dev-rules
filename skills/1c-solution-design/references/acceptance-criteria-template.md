### Алфавит статусов (обеих колонок)

| Пометка | Значение | Кто ставит |
|---|---|---|
| ☐ | не проверялся | — (начальное) |
| ✅ | проверен живым прогоном, соответствует | 05, 06 |
| ✅с | проверен статически, без живой базы (evidence в 05); интерактивная проверка — на внешней приёмке | 05 |
| ⏳ | статически не проверяем — передан на внешнюю приёмку (05); не проверен, приёмка отложена (06) | 05, 06 |
| ❌ | не соответствует: красная строка, самовозврат класс A (05); замечание приёмщика (06) | 05, 06 |
| n/a | неприменим (строка исключена возвратом класса B) — с пояснением в истории изменений | 05/06 |

Правила заполнения:

- «Шаг сценария» — номер шага из 02 (счастливый путь или отклонение).
- «Проверка» — конкретный способ: «ручная, шаг 2», «unit: ТестИмя», «BDD:
  Сценарий <имя>» (Vanessa Automation — скил `1c-testing`).
- Сравнительный критерий («не хуже/не дольше, чем до изменений») — в «Проверке»
  обязательна ссылка на базлайн «до» из карточки 01 (дата, значение, условия);
  базлайна нет — критерий переформулируется в абсолютный (`1c-planning`).
- Критерий, упавший ❌ в двух раундах протокола 06, на следующей итерации
  проверяется unit/BDD-тестом: «Проверка» меняется с «ручная» на
  «unit: ИмяТеста»/«BDD: Сценарий» (правило `rework-rules`; заготовка —
  в Gherkin-секции ниже).
- Критерий успеха карточки (01) без критерия приёмки — 🔴 запрещено (DoD).
- Источник критерия приёмки: критерий успеха из 01 — без пометки; критерий из
  отклонения 02 (раздел «Отклонения») — пометка «[Откл]» в начале формулировки
  (трассировка на шаг 02 обязательна, запись в историю изменений не требуется).
  Критерий без источника в 01/02 — 🔴 ошибка проектирования; согласованное уточнение
  фиксируется в истории изменений.


## Порядок заполнения статусов

- **Внутренняя приёмка** (`05-internal-acceptance.md`) — заполняет «Статус 05»
  по всем строкам с evidence; ❌ — самовозврат в разработку (класс A).
- **Внешняя приёмка** (`06-acceptance-protocol.md`) — заполняет «Статус 06»,
  подтверждая (✅) или оспаривая (❌) статус 05; спорные строки → лист возврата
  с классом A/B/D (`1c-external-acceptance`); новое за пределами матрицы →
  класс C, новая задача. При решении «Отложено» — ⏳ по непроверенным строкам.
- Итоговый статус критерия — колонка «Статус 06»; пока пуста — «Статус 05».

> Формат до 0.13.0 — одна колонка «Статус» с составными записями
> («✅ статич. (05) / ⏳ интерактивно»). Новые артефакты ведутся в двух
> колонках; существующие не переписываются — `delivery_tools.py` читает оба формата.
