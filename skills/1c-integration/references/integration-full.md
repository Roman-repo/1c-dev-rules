## №748 — Таймауты при работе с внешними ресурсами

**Критичность:** 🔴 Блокирующее

**Суть:** Любое обращение к внешнему ресурсу (HTTP, COM, файловая система, БД через ODBC) **обязательно** с таймаутом. Иначе зависший внешний сервис заморозит сеанс 1С навсегда.

❌ **Неправильно:**
```bsl
HTTPСоединение = Новый HTTPСоединение("api.example.com", 80);   // нет таймаута
```

✅ **Правильно:**
```bsl
HTTPСоединение = Новый HTTPСоединение("api.example.com", 80, , , , 30);  // 30 сек
// или через ИнтернетПрокси / параметр Таймаут
```

📖 [Полный текст](https://github.com/zeegin/v8std/blob/main/docs/std/748.md)
См. также: №794

## №794 — Ограничения на использование внешних ресурсов

**Критичность:** 🔴 Блокирующее

**Суть:** Не обращаться к внешним ресурсам в «горячих» местах: в циклах, в часто вызываемых обработчиках, в динамических списках, в проведении документов. Внешний вызов должен быть осознанным, асинхронным и устойчивым к недоступности.

📖 [Полный текст](https://github.com/zeegin/v8std/blob/main/docs/std/794.md)
См. также: №748, №642 (фоновые задания)

## №771 — Интеграция через формат EnterpriseData

**Критичность:** 🟡 Важно

**Суть:** Для обмена между конфигурациями предпочтительнее формат EnterpriseData (CAN-документы), а не произвольные планы обмена. Это стандартный, поддерживаемый формат с преобразованиями.

📖 [Полный текст](https://github.com/zeegin/v8std/blob/main/docs/std/771.md)

---

## №701 — Разработка планов обмена с отборами

**Критичность:** 🟡 Важно

**Суть:** План обмена с отборами — для распределённой базы или узлов по условию. Правила регистрации изменений должны учитывать отбор узла, иначе данные не дойдут или пойдут лишние.

📖 [Полный текст](https://github.com/zeegin/v8std/blob/main/docs/std/701.md)

---

## №798 — Использование ботов системы взаимодействия

**Критичность:** 🟢 Рекомендация

**Суть:** При использовании ботов 1С:Облака/системы взаимодействия — обрабатывать недоступность сервиса, не блокировать основной интерфейс.

📖 [Полный текст](https://github.com/zeegin/v8std/blob/main/docs/std/798.md)

## Мини-чек-лист по интеграции

- [ ] Все внешние вызовы — с таймаутом (№748)
- [ ] Внешние вызовы не в циклах и не в проведении (№794)
- [ ] Тяжёлые обмены — в фоновых заданиях (№642)
- [ ] Для обмена между конфигурациями — EnterpriseData (№771)
- [ ] Планы обмена учитывают отборы узлов (№701)
