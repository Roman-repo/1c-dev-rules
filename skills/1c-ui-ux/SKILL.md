# 1c-ui-ux — командный интерфейс и UX

> UI-логика в форме, но через декларативные механизмы (условное оформление), а не код. Сообщения пользователю — с привязкой к полю.

## 🔴 №418 — Сообщения пользователю

`Сообщить(...)` — для лога. Для пользователя — `СообщитьПользователю(...)` с **привязкой к полю**.

```bsl
// ❌ без привязки — пользователь не понимает, к чему
Сообщить("Заполните количество");

// ✅ с привязкой — ошибка подсветит поле
СообщитьПользователю(
    НСтр("ru = 'Не заполнено количество в строке %1.'"), НомерСтроки,
    "Количество", "Товары", Отказ);
```

## 🔴 №399 / №400 — Доступность/видимость и сообщения через условное оформление

Доступность, видимость, подсветка полей — через **условное оформление** (декларативно), не `Элементы.X.Доступность = Ложь` кодом в `ПриИзменении`.

Сообщения об ошибках — с привязкой к полю (№400), не «в лог».

## №404 — Открытие форм

- Формы открываются программно через `ОткрытьФорму(...)`, не модально (№703).
- Параметры формы — через `Параметры` структуры, не через глобальные переменные.

## 🟡 Командный интерфейс

- Команды — в командных группах осмысленно (`ПанельДействий.Создать`, `ПанельДействий.Отчеты`).
- Подсистемы — отражают бизнес-разделы, не технические слои.
- Не перегружайте интерфейс: каждая команда/подсистема должна использоваться.

## 🟡 Стилистика

- Стили — через стандартные платформы + общие стили конфигурации. Не «точечная» настройка шрифтов/цветов кодом.
- Цветовая индикация (красный/зелёный) — через условное оформление, не через `ЦветТекстаПоля`.

## 🟡 Эстетика и эргономика

- Поля — выровнены, группы осмысленные.
- Обязательные поля — с пометкой `ПроверкаЗаполнения` (через `Обязательность` свойства).
- Шапка → табличные части → «доп. информация» — стандартный порядок.

## Мини-чек-лист по UI/UX

- [ ] Сообщения — `СообщитьПользователю` с привязкой к полю (№418/№400)
- [ ] Доступность/видимость — через условное оформление, не кодом (№399)
- [ ] Формы — через `ОткрытьФорму`, не модально (№404/№703)
- [ ] Команды — в осмысленных командных группах
- [ ] Стили — стандартные, не «точечные» цвет/шрифт кодом
- [ ] Цветовая индикация — через условное оформление
