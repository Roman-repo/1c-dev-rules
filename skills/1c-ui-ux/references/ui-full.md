# Карточка: Командный интерфейс

> Ключевые стандарты [v8std](https://github.com/zeegin/v8std) по командному интерфейсу.
> Полный список раздела — в [`standarts/std/ui.md`](../../standarts/std/ui.md).

---

## №711 / №600 — Общие принципы командного интерфейса

**Критичность:** 🟡 Важно

**Суть:** Командный интерфейс строится по принципу «всё под рукой, но без перегрузки». Подсистемы — узкие по смыслу, команды в них — сгруппированы. Элементы, не относящиеся к текущей задаче, — в подменю «См. также» (№601), не в основной панели.

📖 №711 [принципы](https://github.com/zeegin/v8std/blob/main/docs/std/711.md) · №600 [КИ](https://github.com/zeegin/v8std/blob/main/docs/std/600.md)

---

## №566 / №590 — Командные панели и частотные кнопки

**Критичность:** 🟡 Важно

**Суть:** На командной панели формы — только **часто используемые** кнопки (Создать, Открыть, Провести, Печать). Редкие — в подменю «Ещё» (№528). Не дублировать стандартные кнопки.

📖 №566 [рекомендации](https://github.com/zeegin/v8std/blob/main/docs/std/566.md) · №590 [частотные кнопки](https://github.com/zeegin/v8std/blob/main/docs/std/590.md)
См. также: №528

---

## №573 / №574 — Порядок и названия команд в панели навигации

**Критичность:** 🟡 Важно

**Суть:** Команды в панели навигации формы — в логическом порядке (от общего к частному: Список → Документы-основания → Связанные). Названия — существительные во множественном числе (Заявки, Наряды, Акты), не глаголы.

📖 №573 [порядок](https://github.com/zeegin/v8std/blob/main/docs/std/573.md) · №574 [группировка](https://github.com/zeegin/v8std/blob/main/docs/std/574.md)

---

## №397 — Списки данных с помощью общих команд

**Критичность:** 🟡 Важно

**Суть:** Переход к спискам связанных объектов — через общие команды БСП, а не индивидуальные команды на каждой форме. Это даёт единообразие и поддерживаемость.

📖 [Полный текст](https://github.com/zeegin/v8std/blob/main/docs/std/397.md)

---

## №423 / №596 — Иконки командных панелей

**Критичность:** 🟢 Рекомендация

**Суть:** Иконки — из стандартной библиотеки БСП, единого стиля. Не плодить разные визуальные стили. Размер — стандартный (16/32). SVG предпочтительнее.

📖 №423 [иконки КП](https://github.com/zeegin/v8std/blob/main/docs/std/423.md) · №596 [требования к изображениям](https://github.com/zeegin/v8std/blob/main/docs/std/596.md)

---

## №695 — Командные панели табличных частей

**Критичность:** 🟢 Рекомендация

**Суть:** Командная панель табличной части — с автозаполнением, без жёстко заданных кнопок. Стандартные (Добавить/Удалить/Скопировать) — автоматически. Специфичные — добавляются осознанно.

📖 [Полный текст](https://github.com/zeegin/v8std/blob/main/docs/std/695.md)

---

## №537 — Команды по модификации объектов

**Критичность:** 🟡 Важно

**Суть:** Команды модификации (провести, отменить проведение, пометить удаление, установить статус) — через общие команды БСП с обработчиками в модуле менеджера. Не индивидуальные команды в каждой форме. Это даёт единообразие и доступность из любых списков.

📖 [Полный текст](https://github.com/zeegin/v8std/blob/main/docs/std/537.md)

---

## №620 — Командная панель формы

**Критичность:** 🟡 Важно

**Суть:** На командной панели формы — автозаполнение + несколько специфичных кнопок. Не дублировать стандартные (Записать, Провести — уже есть). Подгруппа «Печать» — только если печатных форм много. Часто используемые кнопки — слева, редкие — в «Ещё».

📖 [Полный текст](https://github.com/zeegin/v8std/blob/main/docs/std/620.md)
См. также: №566, №528

---

## №716 — Командная панель документа

**Критичность:** 🟡 Важно

**Суть:** Командная панель формы документа — стандартный набор: Создать/Скопировать (в подменю «Создать»), Провести/Отменить проведение, Печать, Отправить. В подменю «Создать на основании» — документы-основания. Не плодить лишнего.

📖 [Полный текст](https://github.com/zeegin/v8std/blob/main/docs/std/716.md)
См. также: №620

## Мини-чек-лист по командному интерфейсу

- [ ] Подсистемы узкие, команды сгруппированы (№711)
- [ ] На КП только частотные кнопки, остальное в «Ещё» (№566/590)
- [ ] Команды навигации в логическом порядке, названия — существительные (№573/574)
- [ ] Переход к связанным спискам — через общие команды (№397)
- [ ] Иконки единого стиля (№423)
