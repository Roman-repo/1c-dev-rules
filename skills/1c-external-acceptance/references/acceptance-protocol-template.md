# Лист возврата — <ID задачи> (06a-rework-list.md)

> Заполняется только при решении «Возврат». Каждое замечание — отдельная
> строка с классом и целевым этапом. Повторная приёмка проверяет пункты
> этого листа и изменённые строки 04 — не всю задачу с нуля.

| № | Замечание (цитата) | Класс | Целевой этап | Что сделать | Исправлено (дата) | Перепроверено (дата) |
|---|---|---|---|---|---|---|
| | | A/B/D | | | | |

Правила:

- Класс B: сначала обновить 02/03/04 (история изменений в артефактах),
  затем доработка затронутой части; полный перепрогон — по решению проектировщика.
- Класс A/D: правка + перепрогон затронутых шагов (05) + ревью изменённого кода.
- Строки «Исправлено/Перепроверено» заполняются после возврата; лист
  закрывается только когда все строки перепроверены.
