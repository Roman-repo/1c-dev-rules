# Карточка: Отчёты и печатные формы

> Ключевые стандарты [v8std](https://github.com/zeegin/v8std) по отчётам и печати.
> Полный список раздела — в [`standarts/std/reports.md`](../../standarts/std/reports.md).

---

## №548 — Формирование печатных форм

**Критичность:** 🔴 Блокирующее

**Суть:** Печатные формы — через БСП-механизм (`УправлениеПечатью`), а не самописные процедуры. Это даёт: очередь печати, пакетную печать, сохранение в файл, редактирование пользователем. Новая печатная форма регистрируется в общем модуле `Печать` (или аналогичном) и в справочнике `ПечатныеФормы` БСП.

📖 [Полный текст](https://github.com/zeegin/v8std/blob/main/docs/std/548.md)
См. также: №789

## №670 / №671 — Содержание и варианты отчётов СКД

**Критичность:** 🔴 Блокирующее

**Суть:** Отчёты — на СКД, через механизм вариантов отчётов БСП. Не разрабатывать «отдельную форму» для каждого отчёта, если можно обойтись СКД-вариантом. Варианты — в справочнике `ВариантыОтчетов`.

📖 №670 [содержание](https://github.com/zeegin/v8std/blob/main/docs/std/670.md) · №671 [варианты](https://github.com/zeegin/v8std/blob/main/docs/std/671.md)

## №407 — Применение параметров отчёта в СКД

**Критичность:** 🟡 Важно

**Суть:** Параметры СКД, которые пользователь может задавать — с признаком «Использование.Пользовательский». Параметры, которые задаёт код — через `КомпоновщикНастроек.ПараметрыДанных.УстановитьЗначениеПараметра(...)`. Не вшивать параметры в текст запроса набора данных.

📖 [Полный текст](https://github.com/zeegin/v8std/blob/main/docs/std/407.md)

## №789 — Печатные формы с учётом правки макета пользователем

**Критичность:** 🟡 Важно

**Суть:** Макет печатной формы должен допускать корректировку пользователем (через БСП-механизм «Дополнительные макетыы»). Не «зашивать» логику расположения в код так, что изменение макета ломает печать.

📖 [Полный текст](https://github.com/zeegin/v8std/blob/main/docs/std/789.md)

## №645 — Названия печатных форм и команд

**Критичность:** 🟢 Рекомендация

**Суть:** Названия печатных форм — в едином стиле: существительное + «(вид)». Например «Акт о выполнении этапа работ (проект)». Команды печати — с глаголом: «Печать», «Печать по актам».

📖 [Полный текст](https://github.com/zeegin/v8std/blob/main/docs/std/645.md)

## №672 — Поля периодов

**Критичность:** 🟡 Важно

**Суть:** В отчётах на СКД используйте стандартные поля периодов (`НачалоПериода`, `КонецПериода`) из БСП, а не самописные. Это даёт единообразие с другими отчётами и корректную работу с разными типами периодов (день/неделя/месяц).

📖 [Полный текст](https://github.com/zeegin/v8std/blob/main/docs/std/672.md)

---

## №673 — Пользовательские настройки

**Критичность:** 🟡 Важно

**Суть:** Пользовательские настройки отчёта (отборы, группировки) — через стандартный механизм БСП `КлючПользовательскихНастроек`. Не самописное сохранение. Настройки сохраняются и восстанавливаются автоматически, пользователь может иметь несколько вариантов.

📖 [Полный текст](https://github.com/zeegin/v8std/blob/main/docs/std/673.md)
См. также: №557

## Мини-чек-лист по отчётам и печати

- [ ] Печатные формы через БСП `УправлениеПечатью`, не самописные (№548)
- [ ] Отчёты — на СКД, через варианты БСП (№670/671)
- [ ] Параметры СКД — через компоновщик, не вшиты в запрос (№407)
- [ ] Макеты допускают правку пользователем (№789)
