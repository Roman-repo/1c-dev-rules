# Практика: Скелеты модулей

> Канонические шаблоны областей (`#Область`) для общих модулей, модулей объекта/менеджера и модулей формы.
> Адаптировано из [`module-structure.md`](https://github.com/comol/ai_rules_1c/blob/main/content/rules/module-structure.md) репозитория `ai_rules_1c`.

## Когда применять

Перед созданием нового модуля или реструктуризацией существующего — единый источник правды для имён `#Область`, директив препроцессора и обязательных регионов.

---

## Общий модуль

```bsl
#Область ПрограммныйИнтерфейс

#КонецОбласти

#Область СлужебныйПрограммныйИнтерфейс

#КонецОбласти

#Область СлужебныеПроцедурыИФункции

#КонецОбласти
```

- **`ПрограммныйИнтерфейс`** — публичные экспортные процедуры/функции; то, что другие модули конфигурации могут вызывать.
- **`СлужебныйПрограммныйИнтерфейс`** — экспортные процедуры/функции, предназначенные только для собственных модулей проекта (конвенция БСП: не вызывать из стороннего кода).
- **`СлужебныеПроцедурыИФункции`** — внутренние помощники, никогда без `Экспорт`.

📖 Стандарт: [№469](https://github.com/zeegin/v8std/blob/main/docs/std/469.md) Правила создания общих модулей

---

## Модуль объекта / менеджера

```bsl
#Если Сервер Или ТолстыйКлиентОбычноеПриложение Или ВнешнееСоединение Тогда

#Область ПрограммныйИнтерфейс

#КонецОбласти

#Область ОбработчикиСобытий

#КонецОбласти

#Область СлужебныеПроцедурыИФункции

#КонецОбласти

#КонецЕсли
```

🔴 Внешний блок `#Если Сервер Или ТолстыйКлиентОбычноеПриложение Или ВнешнееСоединение Тогда` — **обязателен** для модулей объекта и менеджера.

📖 Стандарт: [№486](https://github.com/zeegin/v8std/blob/main/docs/std/486.md) Модуль объекта/менеджера

## Модуль формы

```bsl
#Область ОбработчикиСобытийФормы

#КонецОбласти

#Область ОбработчикиСобытийЭлементовШапкиФормы

#КонецОбласти

#Область ОбработчикиСобытийЭлементовТаблицыФормыИмяТаблицы

#КонецОбласти

#Область ОбработчикиКомандФормы

#КонецОбласти

#Область СлужебныеПроцедурыИФункции

#КонецОбласти
```

Все 5 областей модуля формы **обязательны**, даже пустые. Для каждой табличной части формы — своя область `ОбработчикиСобытийЭлементовТаблицыФормы<ИмяТаблицы>` (замените `<ИмяТаблицы>` на имя табличной части).

📖 Стандарт: [№630](https://github.com/zeegin/v8std/blob/main/docs/std/630.md) Правила создания модулей форм

## Глобальные правила

- 🔴 **Имена областей — русские, в стиле БСП.** Английские (`Public`/`Internal`/`Private`) **нельзя** — кроме случая, когда вся конфигурация уже ведётся на английской локали.
- 🔴 **Области внутри процедур/функций — запрещены.**
- 🔴 **Псевдообласти через комментарии — запрещены** — используйте только `#Область` / `#КонецОбласти`.
- 🟡 **Не переименовывать, не удалять, не менять порядок канонических областей.** Если секция пустая — оставьте её пустой.

---

## Чек-лист ревью структуры модуля

- [ ] Имена областей — русские, в стиле БСП
- [ ] Общий модуль: `ПрограммныйИнтерфейс` → `СлужебныйПрограммныйИнтерфейс` → `СлужебныеПроцедурыИФункции`
- [ ] Модуль объекта/менеджера: обёрнут в `#Если Сервер Или ТолстыйКлиент...`
- [ ] Модуль формы: 5 обязательных областей, отдельная область на каждую ТЧ
- [ ] Нет областей внутри процедур/функций
- [ ] Нет псевдообластей через комментарии
