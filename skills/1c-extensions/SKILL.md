# 1c-extensions — расширения (CFE)

> Расширения (Configuration Extension) — механизм правки типовых конфигураций без изменения основного объекта. Правила работы — в стандартах и практике проекта.

## 🔴 В заимствованном модуле — только перехватчики

Код в модуле расширения (заимствованном из основной конфигурации) — **только** через аннотации перехвата:

| Аннотация | Когда | Что делает |
|---|---|---|
| `&Перед` | Перед оригинальным методом | Дополнительная логика до; оригинал выполнится сам |
| `&После` | После оригинального метода | Дополнительная логика после |
| `&Вместо` | Вместо оригинального метода | Полная замена; оригинал НЕ выполнится, если не вызвать `ПродолжитьВызов` |
| `&ИзменениеИКонтроль` | Обёртка над оригиналом | Обёртка с контролем; `ПродолжитьВызов` — обязательно |

🔴 Обычный код (без аннотации) в заимствованном модуле — **нельзя**.

## 🔴 `&ИзменениеИКонтроль` без `ПродолжитьВызов()` — оригинал не выполнится

Если в `&ИзменениеИКонтроль` не вызвать `ПродолжитьВызов(...)`, оригинальный метод **молча не выполнится**. Это частый источник багов.

```bsl
&ИзменениеИКонтроль("ИмяПроцедуры")
Процедура Расш1_ИмяПроцедуры(Параметры)
    // ... доп. логика до ...
    ПродолжитьВызов(Параметры);   // ОБЯЗАТЕЛЬНО — иначе оригинал не выполнится
    // ... доп. логика после ...
КонецПроцедуры
```

## 🔴 `&Вместо` — осторожно

`&Вместо` полностью заменяет оригинальный метод. Оригинал не выполнится, если не вызвать `ПродолжитьВызов`. Используйте, только если действительно нужна полная замена.

## 🟡 Именование процедур в расширении

Имена процедур-перехватчиков — с префиксом расширения: `Расш1_ИмяПроцедуры`, `Расш2_…`. Это требование платформы, не совет.

## 🟡 Минимум заимствований

Заимствуйте только то, что нужно изменить. Не заимствуйте «на всякий случай» — это усложняет обновление основной конфигурации.

## 🟡 Тестирование при обновлении основной конфигурации

После обновления основной конфигурации (БСП и пр.) — **проверьте расширение**: сигнатуры заимствованных методов могли измениться, перехватчики сломаются.

---

## Мини-чек-лист по расширениям

- [ ] В заимствованном модуле — только `&Перед`/`&После`/`&Вместо`/`&ИзменениеИКонтроль`
- [ ] `&ИзменениеИКонтроль` — с `ПродолжитьВызов()` (иначе оригинал не выполнится)
- [ ] `&Вместо` — осознанно (полная замена), `ПродолжитьВызов` если нужен оригинал
- [ ] Имена процедур — с префиксом расширения (`Расш1_…`)
- [ ] Минимум заимствований — только то, что меняется
- [ ] Проверка после обновления основной конфигурации
