# 1c-localization — локализация и многоязычность

> Все тексты, видимые пользователю, — через `НСтр(...)`. Это касается сообщений, исключений, заголовков, текстов СКД.

## 🔴 №761 — Интерфейсные тексты в коде

Все строки, видимые пользователю, — через `НСтр(...)`. Не «голые» строки.

❌ `Сообщить("Не удалось выполнить операцию.");`
✅ `Сообщить(НСтр("ru = 'Не удалось выполнить операцию.'"));`

Касается:
- `Сообщить`, `СообщитьПользователю`
- `ВызватьИсключение` (№790)
- `ПоказатьВопрос`, `ПоказатьПредупреждение`
- Тексты в `ЗаписьЖурналаРегистрации` (технические — можно без `НСтр`, но лучше с)

## 🔴 №762 — Запросы и СКД: локализация

Тексты в запросах СКД и полях — локализуются через `НСтр` или свойства СКД. Заголовки полей — через `<title>` в схеме, с `key=ru`/`key=en`.

## 🟡 №765 — Элементы форм: локализация

Заголовки элементов формы, подсказки, группы — через свойства формы (многоязычные). Не «голый» текст в `Заголовок`.

## Формат `НСтр`

```bsl
НСтр("ru = 'Текст на русском.'")
НСтр("ru = 'Один'; en = 'One'; es = 'Uno'")
```

- Параметры — через `%1`, `%2`: `НСтр("ru = 'Строка %1.'")`, подстановка через `СтрШаблон` или параметр функции.

## 🟡 Локализация метаданных

Синонимы объектов метаданных — на нескольких языках (`<key>ru</key>`, `<key>en</key>`, `<key>es</key>`). Не только `ru`.

## 🟡 Буква `ё` в именах метаданных

В **именах** метаданных и переменных `ё` **запрещена**. В пользовательских текстах (через `НСтр`, в синонимах) — допустима.

## Мини-чек-лист по локализации

- [ ] Все видимые пользователю тексты — через `НСтр` (№761)
- [ ] `ВызватьИсключение` — с `НСтр` (№790)
- [ ] Сообщения ЖР — с `НСтр` (рекомендуется)
- [ ] Тексты СКД — через `<title>` с `key=ru`/`en` (№762)
- [ ] Элементы формы — многоязычные заголовки (№765)
- [ ] Синонимы метаданных — ru/en (+es если нужно)
- [ ] `ё` в именах метаданных/переменных — нет; в пользовательских текстах — ок
