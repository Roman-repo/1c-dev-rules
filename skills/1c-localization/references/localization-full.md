# Карточка: Локализация и многоязычность

> Ключевые стандарты [v8std](https://github.com/zeegin/v8std) по локализации.
> Полный список раздела — в [`standarts/std/localization.md`](../../standarts/std/localization.md).
>
> ℹ️ В проект многоязычность используется (есть `en`, `es` синонимы) — раздел релевантен.

---

## №458 — Общие требования по локализации конфигурации

**Критичность:** 🟡 Важно

**Суть:** Конфигурация должна корректно работать на любом языке интерфейса. Все интерфейсные тексты — мультиязычные (через синонимы метаданных или `НСтр`), все данные — в национальном формате, который конвертируется корректно.

📖 [Полный текст](https://github.com/zeegin/v8std/blob/main/docs/std/458.md)

---

## №761 — Интерфейсные тексты в коде

**Критичность:** 🔴 Блокирующее

**Суть:** Любой текст, который видит пользователь (сообщения, заголовки, вопросы), — через `НСтр("ru = '...'; en = '...'; es = '...'")` или через синонимы метаданных. Не литералами на одном языке.

❌ **Неправильно:**
```bsl
ПоказатьПредупреждение(, "Документ не проведён");   // только русский
```

✅ **Правильно:**
```bsl
Текст = НСтр("ru = 'Документ не проведён'; en = 'Document is not posted'");
ПоказатьПредупреждение(, Текст);
```

📖 [Полный текст](https://github.com/zeegin/v8std/blob/main/docs/std/761.md)
См. также: №764, №765

## №762 — Запросы, динамические списки и СКД

**Критичность:** 🟡 Важно

**Суть:** Поля и заголовки в запросах отчётов/списков должны быть локализуемыми. Не вшивать русские заголовки в текст запроса как литералы.

📖 [Полный текст](https://github.com/zeegin/v8std/blob/main/docs/std/762.md)

## №763 — Форматирование даты, числа, Булево

**Критичность:** 🟡 Важно

**Суть:** Не форматировать дату/число вручную через строковые функции. Использовать `Формат()` — он учитывает региональные настройки сеанса.

❌ **Неправильно:**
```bsl
ДатаСтрокой = Прав(Год(Дата), 2) + "/" + Месяц(Дата) + "/...";   // хрупко
```

✅ **Правильно:**
```bsl
ДатаСтрокой = Формат(Дата, "ДЛФ=D");   // учитывает локаль
```

📖 [Полный текст](https://github.com/zeegin/v8std/blob/main/docs/std/763.md)

## №643 — Работа в разных часовых поясах

**Критичность:** 🟡 Важно

**Суть:** Дата/время в данных хранятся в часовом поясе сеанса. При интеграции и обмене — явно преобразовывать через `УниверсальноеВремя`/`МестноеВремя`. Не предполагать UTC или «московское время».

📖 [Полный текст](https://github.com/zeegin/v8std/blob/main/docs/std/643.md)

---

## №778 — Денежные поля

**Критичность:** 🟡 Важно

**Суть:** Денежные суммы — в поле типа `Число(15,2)` или больше, без округлений до копеек в расчётах. Округление — только при отображении пользователю. Не использовать для денег числа с недостаточной точностью.

📖 [Полный текст](https://github.com/zeegin/v8std/blob/main/docs/std/778.md)

---

## №764 — Строковые константные выражения в коде

**Критичность:** 🟡 Важно

**Суть:** Строковые литералы в коде, которые видит пользователь (тексты ошибок, заголовки, сообщения), — через `НСтр("ru = '...'; en = '...'")`. Исключение — строки, которые пользователь не видит (имена файлов, ключи структур) — они не локализуются.

📖 [Полный текст](https://github.com/zeegin/v8std/blob/main/docs/std/764.md)
См. также: №761

## Мини-чек-лист по локализации

- [ ] Интерфейсные тексты — через `НСтр` или синонимы (№761)
- [ ] Форматирование даты/числа — через `Формат()` (№763)
- [ ] Часовые пояса учитываются при обмене (№643)
- [ ] Денежные поля — достаточной точности (№778)
- [ ] Новые объекты — с синонимами хотя бы `ru` и `en` (№458)
