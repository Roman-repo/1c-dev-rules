# 1c-queries — запросы, СКД, динамические списки

> Ключевые стандарты и практика по запросам 1С. Полные карточки — в `references/`.

## Краткая сводка критичных правил

### 🔴 №733 — `СрезПоследних` / `Остатки` с параметрами
Всегда передавайте в ВТ **оба параметра** — дату и отбор. Без них СУБД разворачивает весь регистр.

❌ `СрезПоследних(, )` — читает ВСЕ записи регистра
✅ `СрезПоследних(&ДатаКонца, Объект В (&Массив))`

⚠️ Если регистр «по положению регистратора» и нужен интервал, а не срез — `СрезПоследних` с датой некорректен, нужно предрасчётное решение.

### 🔴 №655 — Нет соединений с ВТ и подзапросами напрямую
Сначала поместите ВТ/подзапрос во временную таблицу, соединяйте уже её.

❌ `ЛЕВОЕ СОЕДИНЕНИЕ Регистр…Остатки(&Дата, ) КАК Ост`
✅ `ВЫБРАТЬ … ПОМЕСТИТЬ ВрОстатки ИЗ Регистр…Остатки(&Дата, ); ВЫБРАТЬ … ЛЕВОЕ СОЕДИНЕНИЕ ВрОстатки КАК Ост`

### 🔴 №436 — Нет запросов в цикле
Соберите массив, один запрос с `В (&Массив)`.

### 🔴 №732 — Динамический список «плоский»
Самый «горячий» запрос формы. Никаких ВТ в соединениях, никаких обращений через точку к ссылкам (`.Ссылка.Организация` — неявное соединение).

Нужно поле из связанной таблицы — лестница паттернов:
1. **Колонка-ссылка** (`Подразделение`) — соединение не нужно: представление платформа получает сама.
2. **Реквизит ссылки** (`КритичностьДефекта`) — одно явное ЛЕВОЕ СОЕДИНЕНИЕ с **обычной** таблицей (не ВТ).
3. Точка (`Таблица.Поле.Подполе`) — запрещена: неявное соединение.

Авто-проверка: `scripts/validate-new-object.sh` — X15 (queryText ДС: ВТ в соединениях, ВТ без даты).

### 🟡 №656 — Нет `ВЫБРАТЬ *`
Перечисляйте только нужные поля.

### 🟡 №434 — `ОБЪЕДИНИТЬ ВСЕ` по умолчанию
`ОБЪЕДИНИТЬ` (без `ВСЕ`) — неявный DISTINCT, дорого.

### 🔴 №658 — Условия `ГДЕ` должны попадать в индекс
Избегайте: функций над полями (`Месяц(Дата)=1`), арифметики, `ПОДОБНО "%…"` (лидирующий `%` — full scan), неявного приведения типов.

## Мини-чек-лист по запросу

- [ ] В `ВЫБРАТЬ` только нужные поля, нет `*` (№656)
- [ ] Отборы в `ГДЕ` по полям таблиц-источников, не по вычисляемым (№658)
- [ ] Нет соединений с ВТ и подзапросами напрямую (№655)
- [ ] ВТ `Остатки`/`СрезПоследних` вызваны с параметрами даты и отбора (№733)
- [ ] Нет запросов в цикле (№436)
- [ ] Временные таблицы с префиксом `Вр`, уничтожаются после использования
- [ ] Для динамического списка — запрос максимально «плоский» (№732)
- [ ] `ОБЪЕДИНИТЬ ВСЕ` по умолчанию, `ОБЪЕДИНИТЬ` только когда дубли недопустимы (№434)

## СКД — ключевые нюансы

- **Поле запроса → Ресурс → Вычисляемое поле** — порядок предпочтения. Проталкивайте вычисления в запрос, чтобы уменьшить объём строк.
- **Параметры периодов ВТ** (`Остатки(&Период, …)`) — **всегда** через параметры, никогда литералами.
- **`ПриКомпоновкеРезультата`** — канонический hook для программного override компоновки. `СтандартнаяОбработка = Ложь` устанавливается **до** `Попытка`.
- **Привилегированный режим** в СКД — парный (`Истина`/`Ложь`) и обоснован комментарием.

## Частые грабли

| Симптом | Причина | Стандарт |
|---|---|---|
| Отчёт «тормозит» | `СрезПоследних` без параметров | №733 |
| Deadlock при выполнении | Соединение с ВТ напрямую | №655 |
| Пользователь ждёт список | Обращение `.Ссылка.X` в динамическом списке | №732 |
| Запрос медленный без видимой причины | `ПОДОБНО "%шаблон"` — full scan | №658 |
| Дубли строк | `ОБЪЕДИНИТЬ ВСЕ` нужен, а стоит `ОБЪЕДИНИТЬ` (или наоборот) | №434 |
