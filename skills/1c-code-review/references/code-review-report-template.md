## Замечания

| № | Замечание | Правило/Стандарт | Место | Статус |
|---|---|---|---|---|
| 1 | | ключ каталога checkbsl / №NNN | <файл>:<строка> | ☐ открыт / ✅ закрыт |

Правила:

- «Доработать» без строки замечания — бессмысленно: исправлять нечего.
  Каждое замечание — про конкретное место кода (файл:строка) и конкретное
  правило (ключ из каталога `references/checkbsl/` или № стандарта — как в
  чек-листе скила).
- Ревью проверяет **качество кода по стандартам**, не требования: спор о
  требованиях — не замечание ревью, а возврат с внешней приёмки по классам
  A/B (`1c-delivery-gate` §3).
- Замечания по правилам с важностью 🔴 (чек-лист, каталог checkbsl) —
  блокирующие: «Одобрено» при открытых 🔴-замечаниях не ставится.
- После правки Ревьюер повторно принимает решение этим же файлом: статусы
  замечаний → ✅, решение обновляется. История — таблица ниже.
