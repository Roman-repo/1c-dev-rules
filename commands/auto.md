Установи режим конвейера разработки **auto** для текущего проекта (роль Оркестратора — `1c-delivery-gate` §0).

1. Определи каталог доставки проекта: по умолчанию `docs/delivery/`; если путь переопределён в `AGENTS.md` проекта — используй проектный.
2. Создай или обнови файл `<каталог-доставки>/_conveyor-mode.md` содержимым:

```markdown
<!-- Режим конвейера разработки (1c-dev-rules). Управляется командами /auto и /manual. -->
mode: auto
updated: <сегодня, ГГГГ-ММ-ДД>
```

3. Если файл уже существовал — сохрани остальные его строки, заменив только `mode:` и `updated:`.
4. Подтверди пользователю: с этого момента гейт 2→3 (согласование пакета 02/03/04) проходится автоматически — Исполнитель ставит штамп «Согласовано» в секцию «Согласование Оркестратора» артефакта 04 с пометкой режима `auto` и датой, без остановки. Ответственность за пропуск живого согласования — на Оркестраторе. Вернуть остановку — командой /manual.
