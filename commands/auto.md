Установи режим конвейера разработки **auto** для текущего проекта (живые гейты — `1c-delivery-gate` §0).

1. Определи каталог доставки проекта: по умолчанию `docs/delivery/`; если путь переопределён в `AGENTS.md` проекта — используй проектный.
2. Создай или обнови файл `<каталог-доставки>/_conveyor-mode.md` содержимым:

```markdown
<!-- Режим конвейера разработки (1c-dev-rules). Управляется командами /auto и /manual. -->
mode: auto
updated: <сегодня, ГГГГ-ММ-ДД>
```

3. Если файл уже существовал — сохрани остальные его строки, заменив только `mode:` и `updated:`.
4. Подтверди пользователю: с этого момента оба живых гейта проходятся автоматически — этап 3 «Согласование» (решение по пакету 02/03/04): Исполнитель создаёт лист замечаний `04a-design-review.md` с решением «Согласовано»; этап 6 «Код ревью»: Исполнитель создаёт лист `05a-code-review.md` с решением «Одобрено». Оба — с пометкой режима `auto` и датой, без остановки. Ответственность за пропуск живого контроля — на Оркестраторе. Вернуть остановки — командой /manual.
