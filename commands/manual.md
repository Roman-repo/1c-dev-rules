Установи режим конвейера разработки **manual** для текущего проекта (этап «Согласование» — `1c-delivery-gate` §0).

1. Определи каталог доставки проекта: по умолчанию `docs/delivery/`; если путь переопределён в `AGENTS.md` проекта — используй проектный.
2. Создай или обнови файл `<каталог-доставки>/_conveyor-mode.md` содержимым:

```markdown
<!-- Режим конвейера разработки (1c-dev-rules). Управляется командами /auto и /manual. -->
mode: manual
updated: <сегодня, ГГГГ-ММ-ДД>
```

3. Если файл уже существовал — сохрани остальные его строки, заменив только `mode:` и `updated:`.
4. Подтверди пользователю: с этого момента после подготовки пакета документации 02/03/04 Исполнитель **останавливается** и предъявляет Оркестратору сводку пакета (сценарий, границы спецификации, критерии приёмки, развилки ADR); решение фиксируется в листе замечаний `04a-design-review.md` — «Согласовано» открывает разработку, «Доработать» возвращает пакет на этап 2 (правка 02/03/04) или этап 1 (до-сбор требований). Это режим по умолчанию (нет файла — действует manual). Убрать остановки — командой /auto.
