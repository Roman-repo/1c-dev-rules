## Стек и формат

- **Плагин ZCode** — манифест `.zcode-plugin/plugin.json` (альтернативные имена каталога для Claude/Codex/Cursor: `.claude-plugin/`, `.codex-plugin/`, `.cursor-plugin/`).
- **Скил** = каталог `skills/<name>/` с `SKILL.md` (YAML frontmatter: `name`, `description` ≤1024 симв / главное в первых ~250, `when_to_use`, `license`) + опционально `references/*.md` (progressive disclosure).
- **Источники контента:** `zeegin/v8std` (стандарты), `comol/ai_rules_1c` (practice, public domain), `Nikolay-Shirokov/cc-1c-skills` (спецификации форматов). Ссылки на стандарты — на `github.com/zeegin/v8std/blob/main/docs/std/NNN.md`.
- **Принцип:** скилы **универсальны** — без упоминаний конкретных конфигураций (`торо_`, `Project/Toir`). Проектная специфика — в `AGENTS.md` проекта (генерируется скилом `1c-project-bootstrap`).
