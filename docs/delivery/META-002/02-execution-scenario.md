# Сценарий исполнения — META-002: Три слоя ревью одной командой обёртки

**Источник:** карточка задачи `01-task-brief.md` (критерии успеха № 1–4);
ретроспектива META-001 (кэш проектного обхода, 9,7 с) и миссия п.11 промпта 0.32.0.

**Участники (роли процесса):**
- Разработчик (Исполнитель) — петля самоочистки этапа 6: правит код/XML, запускает обёртку, исправляет находки
- Обёртка (Система) — `scripts/bsl_ls_analyze.py`: запускает слои, сливает, применяет подавления, пишет отчёт `bsl-ls-r<N>.md`
- Metadata-слой (Система) — `scripts/metadata_scan.py`, вызывается обёрткой на тех же входах (standalone-CLI сохраняется)
- Ревьюер — этап 6 «Код ревью», переносит находки слоёв в лист 05a, подавляет «не баг»

**Предусловия:** целевой репо с EDT-выгрузкой (`src/`: `.bsl`, `.mdo`, `.rights`, `Configuration.mdo`); git доступен; python ≥ 3.9 (stdlib); для слоя 2 — Java 21+ и jar (как сейчас); плагин ≥ 0.32.0 (есть `metadata_scan.py`).

**Постусловия:** одна команда обёртки на диффе задачи даёт находки всех трёх детерминированных слоёв в одном отчёте с дедупом и общими подавлениями; счётчик `--coverage-report` учитывает три слоя; повторный прогон петли с `--cache-dir` — секунды, не десятки.

## Счастливый путь

| № | Роль | Шаг (что делает) | Триггер (когда) | Описание | Результат шага |
|---|---|---|---|---|---|
| 1 | Разработчик | Завершает правки задачи | Этап «Разработка», код и метаданные готовы к самопроверке | Правит `.bsl` и/или `.mdo`/`.rights`/`Configuration.mdo` | Git-дифф задачи содержит источники двух типов |
| 2 | Разработчик | Запускает обёртку одной командой | Шаг 1 завершён | `python3 scripts/bsl_ls_analyze.py --diff <REF> --src-root <src> --report docs/delivery/<ЗАДАЧА>/code-review/bsl-ls-r1.md [--suppress suppress.json] [--cache-dir DIR]` | Единый md-отчёт трёх слоёв; exit 0/1 |
| 3 | Обёртка | Запускает metadata-слой на тех же входах | Шаг 2 | `.mdo`/`.rights` из того же диффа (свой git-фильтр слоя)<br>`--src-root` передаётся слою (кросс-файловые проверки)<br>при `--cache-dir` — кэш индекса обхода | Metadata-находки в формате общего пула (ключ, sev, №, файл, строка) |
| 4 | Обёртка | Сливает три слоя с дедупом | Слои 1–3 отработали | Дедуп по (ключ, файл, строка)<br>приоритет при коллизии: metadata → слой 1 → BSL LS | Один отсортированный список находок без дублей |
| 5 | Обёртка | Применяет подавления и пишет отчёт | Шаг 4 | `--suppress` действует на ВСЕ слои (единая точка после слияния)<br>шапка: «+ слой метаданных (metadata_scan.py)» | Отчёт `bsl-ls-r1.md`: находки с меткой слоя, «что не так / как правильно», вердикт петли, секция «Подавленные» |
| 6 | Разработчик | Исправляет 🔴 и повторяет | В отчёте есть 🔴 | Правит по колонке «как правильно»<br>повторный прогон r2, r3… (с `--cache-dir` — быстро) | Отчёт чист по 🔴; раунды в `code-review/` задачи |
| 7 | Ревьюер | Проходит чек-лист и каталог | Отчёт чист по 🔴 | Чек-лист 1c-code-review + каталог checkbsl<br>ссылается на ключи/№ из отчёта | 05a: «Одобрено»/«Доработать» |
