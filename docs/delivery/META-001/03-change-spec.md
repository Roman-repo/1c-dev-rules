| 3 | Кто зависит от изменяемого? | `validate-new-object.sh` (сжимается: формовые проверки + вызов слоя); сьют unittest (+новый файл тестов); README/CHANGELOG (паспорт слоя). Обёртка `bsl_ls_analyze.py` в MVP НЕ трогается |

## Формы и командный интерфейс

Форм нет. Макет не требуется; эквивалент для CLI — образец вывода:

```
$ python3 scripts/metadata_scan.py src/Catalogs/торо_ИдентификаторыТехКарт \
    --diff main --src-root src
Metadata-слой checkbsl: источников в диффе 2 (.mdo, .rights), применимо правил 28
🔴 ObjectWithoutRole (№532, локальный): Catalog.торо_ИдентификаторыТехКарт
     не найден ни в одной роли src/Roles/
   что не так: объект невидим пользователям; право выдаётся ролями, роли нет
   как правильно: добавить объект в профиль/роль … (пример из bsl_ls_fixes.json)
🟡 MDOWithoutSynonym (№474): у объекта нет синонима ru
Итог: 🔴 1  🟡 1  🟢 0 | подавлено: 0 | coverage metadata: 16/32
```

## Нефункциональные требования

| Категория | Требование |
|---|---|
| **Совместимость версий** | python ≥ 3.9, только stdlib (argparse/json/pathlib/xml.etree/re); без Java и сети. Допущение: формат EDT-выгрузки стабилен — тесты на живом дереве ТОИР, при смене формата правим парсер по факту (риск из 01) |
| **Объёмы и нагрузка** | Дифф-режим: десятки файлов, <1 с. Проектные обходы (UUID, Roles/): <5 с на дереве 2627 модулей (замер в 05) |
| **Регрессия** | Паритет с bash: прогон старого скрипта и слоя на полигоне (объекты TASK-001/002) — множество находок перенесённых проверок совпадает; сьют плагина зелёный (216 + новые); `checkbsl_scan.py`/`bsl_ls_analyze.py` не изменяются |
| **Отказоустойчивость** | Битый XML → WARN по файлу; git-сбой → exit 2; повторный запуск даёт тот же результат |

## Производительность

- Горячие места: os.walk по src для UUID-коллизий и Roles/ (один проход, кэш токенов)
- Целевые показатели: дифф <1 с; полный обход <5 с (базлайн bash rule12 ≈2,6 с)

## Откат

`git revert` коммита слоя: `metadata_scan.py`/тесты — новые файлы,
`validate-new-object.sh` возвращается целиком (правка атомарна в одном
коммите). Артефакты конвейера задачи сохраняются.
