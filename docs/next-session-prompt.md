## 6. Критические правила

- Плагин 1c-* v0.35.0: задача → `1c-delivery-gate`; код → `1c-dispatch-gate`; эпик → `1c-epic-planning`.
- Живые гейты: согласование 04a и код-ревью 05a; без `_conveyor-mode.md` действует `manual`.
- Не выдумывай функции: нестандартный метод сначала найди в проекте через `grep`.
- TOIR: прикладные префиксы `торо_`/`гкс_`; БСП не править; `ё` в именах метаданных запрещена.
- Новые UUID — только случайные; роли новых объектов обязательны; правки XML вслепую явно помечать непроверенными EDT.
- Скилы: description ≤250 символов, триггеры в видимой зоне; после изменений — валидатор и тесты.
- Новые regex-правила — в `checkbsl_scan.py` с позитивным/негативным тестом; XML — в `metadata_scan.py`.
- После каждой фичи предложи 1–3 улучшения, не реализуя их без согласия.
- Merge PR — только по явному запросу пользователя, без проверки статуса CI; локальные проверки обязательны.
