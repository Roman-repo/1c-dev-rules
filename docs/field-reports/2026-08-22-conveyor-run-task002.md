## Отклонения плагина

### №1 — delivery_tools.py: легенда «Алфавит статусов» парсится как критерии

```
[Скрипт] delivery_tools.py — ложное срабатывание гейта 2→3
Пример: TASK-002, 04-acceptance-criteria.md, шаблон 0.13.0+: таблица-легенда
  «### Алфавит статусов (обеих колонок)» лежит внутри секции «## Матрица
  трассировки и критерии приёмки»; md_sections режет только по «##», таблицы
  секции склеивались в одну → 7 строк легенды (Пометка, ☐, ✅, ✅с, ⏳, ❌, n/a)
  становились «критериями» с пустыми ячейками → ERR 14, гейт ложно заблокирован.
Предложение: разбивать секцию на отдельные таблицы (split_tables) и в
  parse_matrix брать только таблицы с колонкой «Критерий».
Класс: 🟡 ложное срабатывание
```

Статус: исправлено в 0.17.1 (split_tables + фильтр по колонке «Критерий»,
регрессионный тест `test_matrix_legend_table_ignored`; TASK-001 в старом
одно-колоночном формате не пострадал — ERR 0). Временный обход в самом
артефакте TASK-002 (легенда вынесена в отдельную секцию `##`) после фикса
не обязателен, но и не вреден.
