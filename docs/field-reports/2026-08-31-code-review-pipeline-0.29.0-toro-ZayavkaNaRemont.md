## Отклонения плагина (кандидаты на исправление)

### О1. `MagicNumber` срабатывает на цифры внутри идентификаторов — ложное

Строка 13: `торо_ЗаполнениеДокументов20.ЗаполнениеНаОсновании(...)` — находка по «20»
из **имени модуля**, а не из числового литерала. Причина: паттерн `\d+(?:\.\d+)?`
без границ слова. Полезно исправить: добавить границы `(?<![\w.])` / `(?!\w)`,
тест на идентификатор с цифрой.

### О2. `CommentedOutCodeLine` срабатывает на документирующие комментарии — 5 из 6 🟢 ложные

Все 5 находок модуля — прозаические описания методов, а не закомментированный код:

- `// Процедура выполняет движения документа по регистру …` — альтернатива
  `^(Процедура|Функция)\b` стреляет по устоявшемуся стилю документирующих
  комментариев (повтор 0.27.2: то же отклонение уже фиксировалось).
- `// … простановка Обработано = Истина` — ветка `\w+\s*=[^=]` ловит прозу без
  «;» в конце.

Полезно исправить: для `Процедура|Функция` требовать признак сигнатуры
(имя + `(`), для ветки присваивания — завершающую «;»; тесты на живых строках
этого модуля.

### О3. Обёртки падают с exit 120 при усечении вывода пайпом

`bsl_ls_analyze.py … | head -60` → BrokenPipeError на финальном flush, код
выхода 120 вместо документированных 0/1/2/3. Мелочь, но вводит в заблуждение
при автоматизации (CI/скрипты с pipe). Полезно исправить: перехват
BrokenPipeError в `main()` обоих скриптов (нормальный выход по статусу находок).

### О4 (косметика). Фрагменты запросов в консольной md-таблице начинаются с «/»

Замена `|`→`/` (защита таблицы) искажает фрагмент: `/ ИЛИ торо_… ССЫЛКА …`.
В `--report` сниппет честный, касается только консольного вывода. Полезно
исправить: экранировать `\|` вместо замены символа.
