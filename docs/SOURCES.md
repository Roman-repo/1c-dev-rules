# Источники и лицензии

Набор собран из трёх открытых репозиториев. Сохранены ссылки на оригиналы; этот репозиторий — удобная упаковка их в скилы для ИИ-ассистентов.

## Первоисточники

### 1. zeegin/v8std — стандарты разработки 1С

- **URL:** https://github.com/zeegin/v8std
- **Лицензия:** см. репозиторий (open source)
- **Что берём:** ~360 стандартов разработки 1С — оглавления лежат в `std/*.md`, на полные тексты стандартов карточки ссылаются по URL `github.com/zeegin/v8std/blob/main/docs/std/NNN.md`.
- **Как используется:** карточки скилов (`references/*-full.md`) — это **адаптация** стандартов: выжимка сути, примеры «неправильно/правильно», мини-чек-листы. Не копия. При расхождении — приоритет за upstream.

### 2. comol/ai_rules_1c — практика кодирования

- **URL:** https://github.com/comol/ai_rules_1c
- **Лицензия:** public domain
- **Что берём:** practice-карточки — «грабли ручной правки метаданных», «блокировки и транзакции», «проектирование СКД», «скелеты модулей», «архетипы форм», «типовые формы», «расширения», «асинхронные методы», «проектирование регистров».
- **Адаптация:** очищены от проектной специфики, перекрыты ссылками на v8std, добавлены чек-листы.

### 3. Nikolay-Shirokov/cc-1c-skills — спецификации форматов 1С

- **URL:** https://github.com/Nikolay-Shirokov/cc-1c-skills
- **Лицензия:** см. репозиторий
- **Что берём:** спецификации:
  - `1c-support-state-spec.md` — алгоритм определения поддержки объекта (ParentConfigurations.bin, флаги G/f1)
  - `1c-dcs-spec.md` — структура XML-схемы СКД
  - `1c-config-objects-spec.md` — стандартные реквизиты объектов метаданных
  - `1c-configuration-spec.md` — свойства `Configuration.mdo`
- **Используется как есть** (со ссылкой на источник) в скилах `1c-metadata`, `1c-platform-support`, `1c-queries`.

## Сохранение атрибуции

В каждом `references/*.md`, перенесённом из upstream, в подвале секции «Источники» указан оригинал:

```markdown
## Источники

Адаптировано из [`queries.md`](https://github.com/comol/ai_rules_1c/blob/main/content/rules/queries.md)
репозитория `ai_rules_1c`. Стандарты — [zeegin/v8std](https://github.com/zeegin/v8std).
```

## Обновление из upstream

См. [ARCHITECTURE.md → Синхронизация с upstream](./ARCHITECTURE.md#синхронизация-с-upstream).

Кратко: раз в квартал сверять `std/index.md` с актуальным оглавлением v8std, cherry-pickить изменения в карточки, фиксировать в `CHANGELOG.md`.
